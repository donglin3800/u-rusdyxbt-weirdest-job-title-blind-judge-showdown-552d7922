A small Python program that writes a single weird job title — 39 characters — to `/output/entry.txt`: an underwater piano tuner for cruise ships. A piano tuner is a real job, underwater is an impossible workplace, and cruise ships are a real employer, so the title reads like a genuine posting until the second word.

## Run it

```sh
python3 main.py
```
